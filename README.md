# LSB Image Steganography using C

## 📌 Project Description

LSB Image Steganography is a C-based project that hides secret text data inside a BMP image using the **Least Significant Bit (LSB)** technique.

The project supports both **encoding and decoding**. Secret text is embedded into the pixel data of a BMP image, and the hidden data can later be extracted from the stego image.

## ✨ Features

* Hide text data inside a BMP image
* Extract hidden text data from a stego image
* Validate input file formats
* Check image capacity before encoding
* Preserve the BMP header
* Encode and decode magic string
* Encode and decode secret file extension
* Encode and decode secret file size
* Encode and decode secret file data
* Copy remaining image data
* Command-line based execution

## 🔐 How It Works

### Encoding

The secret data is hidden in the **Least Significant Bits (LSB)** of the BMP image's pixel data.

```text
Source BMP Image
       ↓
Open Source & Secret Files
       ↓
Check Image Capacity
       ↓
Copy BMP Header
       ↓
Encode Magic String
       ↓
Encode File Extension
       ↓
Encode File Size
       ↓
Encode Secret Data
       ↓
Copy Remaining Image Data
       ↓
Stego BMP Image
```

### Decoding

The hidden data is extracted from the stego image by reading the LSBs of the encoded pixel data.

```text
Stego BMP Image
       ↓
Decode Magic String
       ↓
Decode File Extension
       ↓
Decode File Size
       ↓
Decode Secret Data
       ↓
Reconstructed Secret File
```

## 🧠 LSB Steganography Concept

LSB steganography works by modifying the **least significant bit** of each pixel byte.

For example:

```text
Original pixel data:
10110100

Secret bit:
       1

Modified pixel data:
10110101
```

Since only the least significant bit is changed, the visual difference between the original image and the stego image is negligible.

## 🚀 Usage

### Encoding

Syntax:

```bash
./stego -e <source.bmp> <secret.txt> <stego.bmp>
```

Example:

```bash
./stego -e beautiful.bmp secret.txt stego.bmp
```

Where:

* `-e` → Encoding operation
* `beautiful.bmp` → Source BMP image
* `secret.txt` → File containing secret data
* `stego.bmp` → Output BMP image containing hidden data

### Decoding

Syntax:

```bash
./stego -d <stego.bmp>
```

Example:

```bash
./stego -d stego.bmp
```

Where:

* `-d` → Decoding operation
* `stego.bmp` → BMP image containing hidden data
